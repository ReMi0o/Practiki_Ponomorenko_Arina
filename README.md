# Практические работы по ИУП — Пономоренко Арина Сергеевна, 4ИСП9-45

Проект для всех работ — сайт записи на мастер-классы **«Мастерская идей»** (PHP 8, SQLite).
Итоговый код: [Код_проекта/](%D0%9A%D0%BE%D0%B4_%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%B0). Версии кода по этапам — в папках `код_этапа` практических работ.

## Запуск
```bash
cd Код_проекта
php database/seed.php                              # тестовые данные, один раз
php -S localhost:8000 -t public public/index.php   # открыть http://localhost:8000
```
Нужен PHP 8.1+ с расширением pdo_sqlite. База создаётся автоматически (`database/masterskaya.sqlite`).
